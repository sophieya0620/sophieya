# 마음 서랍 · 나만의 감정 일기장

오늘의 마음을 **마음 편지**로 써서 서랍에 차곡차곡 간직하는 감정 일기 앱입니다.
기록 하나가 감정 색 편지 한 통이 되고, 감정 얼굴이 봉인 스티커처럼 붙어요.
하얀 바탕에 햇살 노랑·하늘 파랑·다정한 주황을 포인트로, 3D 클레이 느낌의 얼굴 아이콘으로 만들었어요.

## 구성 (3장)

| 장 | 내용 |
|---|---|
| **1장 · 오늘의 마음** | 날짜(하루 최대 10번), 감정 아이콘(긍정 / 중간 / 부정, 최대 3개), 함께한 사람, 별점(5점 만점) |
| **2장 · 마음의 빙산** | 사티어 빙산 모델을 따라 수면 위에서 깊은 곳으로 내려가며 적기 (아래 참고) |
| **3장 · 마음 그림** | 손가락으로 그리는 메모장 (10가지 색, 굵기 3단계, 지우개, 되돌리기, 모두 지우기) |

- 오른쪽 위 서랍 버튼 → **나의 마음 서랍**: 지난 기록 목록, 긍정·중간·부정 비율, 기록 보기 / 고쳐 쓰기 / 삭제

## 하루 최대 10번

같은 날짜에 마음 편지를 최대 10통까지 쓸 수 있어요. 날짜 아래 10칸 표시로 몇 번째 편지인지 보여주고, 편지마다 쓴 시각이 함께 저장돼요.

## 마음의 빙산 (2장)

| 층 | 적는 내용 |
|---|---|
| **수면 위 · 행동** | 어떤 일이 있었고 나는 어떻게 행동했는지, 대처방식(회유형 · 비난형 · 초이성형 · 산만형 · 일치형) |
| **1층 · 감정** | 1장에서 고른 감정, 그 감정을 느낀 이유, 감정에 대한 감정 |
| **2층 · 지각** | 그 일을 어떻게 받아들였는지 (생각 · 믿음 · 가정 · 가치) |
| **3층 · 기대** | 나에 대한 기대, 타인에 대한 기대, 타인이 나에게 바란다고 느낀 기대 |
| **4층 · 열망** | 사랑 · 수용 · 소속감 · 창조성 · 관계 · 안정 · 자유 · 삶의 목적과 의미 중 고르기 + 자유롭게 적기 |
| **가장 깊은 곳 · 자기** | 나는 나 — 깊은 곳의 나에게 건네는 한마디 |

위쪽 빙산 지도를 누르면 그 층으로 바로 이동하고, 적은 층에는 ✓ 표시가 생겨요. 모든 층을 다 채우지 않아도 괜찮아요.

## 삭제 · 임시 삭제함 · 알림

기록을 삭제할 때 두 가지 중에서 고를 수 있어요.

| 방식 | 설명 |
|---|---|
| **임시 삭제** | 임시 삭제함에 보관돼요. 보관 기간은 **3일 · 1주 · 2주 · 1개월 · 3개월** 중에서 골라요 (최소 3일, 최대 3개월). |
| **영구 삭제** | 바로 지워지고 되돌릴 수 없어요. |

- **알림:** 삭제일 기준 **3일이 지나면** 알림 창이 떠서, 기록마다 **복귀 / 계속 보관(기간 다시 선택) / 영구 삭제** 중 하나를 고를 수 있어요.
  - '계속 보관'을 고르면 **영구 삭제 하루 전**에 한 번 더 알려드려요.
  - '나중에 정할게요'를 누르면 다음에 앱을 열 때 다시 알려드려요.
- **안전장치:** 답을 기다리는 기록은 고를 때까지 지우지 않아요. 단, 삭제한 지 3개월이 지나면 자동으로 영구 삭제돼요.
- **설정 (🔔 버튼):** 임시 삭제 알림 켜기/끄기, 휴대폰 알림 켜기/끄기, 기본 보관 기간.
  - 알림을 끄면 보관 기간이 끝나는 대로 영구 삭제돼요.
  - 휴대폰 알림은 앱이 백그라운드에 열려 있을 때 휴대폰 알림으로 보내요. 앱을 완전히 닫았을 때는 다음에 열 때 알림 창으로 알려드려요.
- 임시 삭제함에서는 언제든 복귀, 보관 기간 변경, 영구 삭제, 임시 삭제함 비우기를 할 수 있어요.
- 쓰는 중인 내용은 자동으로 임시 저장돼요 (앱을 닫았다 열어도 그대로).
- 모든 기록은 **내 기기 안에만** 저장됩니다 (서버로 전송하지 않아요).

## 감정 카드 (24개)

상담 현장에서 쓰는 감정카드를 참고해 고른 감정들입니다.

- **긍정**: 기쁜 · 행복한 · 설레는 · 감사한 · 뿌듯한 · 편안한 · 사랑받는 · 신나는
- **중간**: 담담한 · 궁금한 · 놀란 · 멍한 · 생각많은 · 지루한 · 어색한 · 그저그런
- **부정**: 불안한 · 슬픈 · 화난 · 외로운 · 걱정되는 · 서운한 · 지친 · 두려운

## 실행하기

빌드 과정이 없는 웹앱(PWA)입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 휴대폰에 앱으로 설치하기

1. GitHub 저장소 → **Settings → Pages** → Branch를 이 브랜치로 선택하고 저장
2. 생성된 주소를 휴대폰에서 열기
3. iPhone(Safari): 공유 버튼 → **홈 화면에 추가** / Android(Chrome): 메뉴 → **앱 설치**

설치하면 홈 화면 아이콘으로 열리고, 인터넷이 없어도 쓸 수 있어요.

## 파일 구조

```
index.html            화면 구조 (3장 + 마음 서랍 시트)
css/style.css         디자인 (3D 카드, 페이지 넘김 효과)
js/emotions.js        감정 카드 데이터 + 3D 얼굴/별 SVG 생성
js/iceberg.js         마음의 빙산 층 · 대처방식 · 열망 데이터
js/canvas.js          그림 메모장
js/db.js              기기 내 저장소 (IndexedDB)
js/app.js             앱 동작
sw.js, manifest.webmanifest, icons/   앱 설치·오프라인용
```

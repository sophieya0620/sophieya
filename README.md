# 마음 구슬 · 나만의 감정 일기장

오늘의 마음을 **기억 구슬**로 남기는 감정 일기 앱입니다.
하얀 바탕에 햇살 노랑·하늘 파랑·다정한 주황을 포인트로, 3D 클레이 느낌의 얼굴 아이콘으로 만들었어요.

## 구성 (3장)

| 장 | 내용 |
|---|---|
| **1장 · 오늘의 마음** | 날짜, 감정 아이콘(긍정 / 중간 / 부정, 최대 3개), 함께한 사람, 별점(5점 만점) |
| **2장 · 그날의 이야기** | 감정을 느낀 사건, 그 감정을 고른 이유 |
| **3장 · 마음 그림** | 손가락으로 그리는 메모장 (10가지 색, 굵기 3단계, 지우개, 되돌리기, 모두 지우기) |

- 오른쪽 위 📔 버튼 → **나의 기억 구슬**: 지난 기록 목록, 긍정·중간·부정 비율, 기록 보기 / 고쳐 쓰기 / 지우기
- 쓰는 중인 내용은 자동으로 임시 저장돼요 (앱을 닫았다 열어도 그대로).
- 모든 기록은 **내 기기 안에만** 저장됩니다 (서버로 전송하지 않아요).

## 감정 카드 (24개)

상담 현장에서 쓰는 감정카드를 참고해 고른 감정들입니다.

- **긍정**: 기쁜 · 행복한 · 설레는 · 감사한 · 뿌듯한 · 편안한 · 사랑받는 · 신나는
- **중간**: 담담한 · 궁금한 · 놀란 · 멍한 · 생각많은 · 지루한 · 어색한 · 그저그런
- **부정**: 불안한 · 슬픈 · 화난 · 외로운 · 걱정되는 · 서운한 · 지친 · 두려운

## 실행하기

빌드 과정이 없는 웹앱(PWA)입니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### 휴대폰에 앱으로 설치하기

1. GitHub 저장소 → **Settings → Pages** → Branch를 이 브랜치로 선택하고 저장
2. 생성된 주소를 휴대폰에서 열기
3. iPhone(Safari): 공유 버튼 → **홈 화면에 추가** / Android(Chrome): 메뉴 → **앱 설치**

설치하면 홈 화면 아이콘으로 열리고, 인터넷이 없어도 쓸 수 있어요.

## 파일 구조

```
index.html            화면 구조 (3장 + 기록 시트)
css/style.css         디자인 (3D 카드, 페이지 넘김 효과)
js/emotions.js        감정 카드 데이터 + 3D 얼굴/별 SVG 생성
js/canvas.js          그림 메모장
js/db.js              기기 내 저장소 (IndexedDB)
js/app.js             앱 동작
sw.js, manifest.webmanifest, icons/   앱 설치·오프라인용
```
